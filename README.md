# Taskbar App Groups

Fold a row of pinned taskbar icons into a few group icons. Click a group, a flyout opens showing the
apps inside, and hovering an app with open windows gives you live previews of those windows.

Windows 11, 64 bit.

## Download

The newest setup program is on the [releases page](../../releases/latest). One file, about 46 MB.
It needs nothing else installed: .NET is inside it.

1. Download `TaskbarAppGroupsSetup.exe`.
2. Run it. Windows will say **"Windows protected your PC"**, because the file is not signed yet.
   Choose **More info**, then **Run anyway**.
3. The wizard asks whether to install for everybody or just for you, and where. The defaults are
   "for all users" and `C:\Program Files\Taskbar App Groups`.

The app checks this page for newer versions once a day and can install them for you, from its own
settings screen. It never downloads or installs anything without you pressing the button.
